What has been happening

This keeps itself. Nothing here needs pressing. The extension records the shape of every frame each time the control panel opens or closes, every attempt to line two subtitles up with both files' timings, every message you were shown, every attach, and every error that reached the top of a frame or the service worker.

It goes to the daemon, which appends it to subtitle-daemon/logs/ — no files and no download popups. When the daemon is not running it stays in the browser instead, for an evening's viewing if need be, and goes out in one piece the moment the daemon comes up. A file is only downloaded if even that fills, or if you ask for one below. Turn the whole thing off from the control panel's If this page is not working section.

Everything captured

The whole report, as it would be pasted into a bug report. No API key and no cookies. Frame addresses are cut back to the origin and their first path segment, because a player's URL is often a signed one. The page's own address is kept — it is the thing being diagnosed.
