OpenSubtitles API key

Only needed for the extension to fetch subtitles on its own, when the daemon is not running. The daemon keeps its own key in subtitle-daemon/config.local.json and does not use this one.

Downloaded subtitles

The extension and the daemon keep separate stores — a browser extension cannot write to the daemon's folder. Whatever either one has downloaded is copied to the other whenever the daemon is running, so a download is never spent twice. Held says where each one currently is.

Dictionary and translation for study mode

Both come from the daemon when it is running. Without it the extension can ask api.dictionaryapi.dev for what a word means and api.mymemory.translated.net for what it is in your other subtitle's language — but only if you allow it here. The extension asks for no other site, and that stays true unless you turn this on. Marking rare words and saving them with their line work either way.
